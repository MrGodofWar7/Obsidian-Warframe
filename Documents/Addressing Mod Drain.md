Can't fit a mod? You need to make use of the following items:

- Forma / Omni Forma / Umbra Forma
- Orokin Catalyst (for weapons) / Orokin Reactor (for Warframes, Companions, Archwings and Necramechs)

# Polarization: Halving Cost

Let's say you're trying to fit a Galvanized mod with 16 Drain such as Galvanized Chamber. The only way to decrease the Drain cost is to have the matching polarity (as shown on the top right corner of the mod to the right of the Drain cost number) which will result in it being **halved**. This is achieved with using **Forma**.

## Forma Sources

In order of reliability:
- Void Relics (as a blueprint)
- Rare Orokin Containers in the Void (fully built)
- Rare Caskets in the Zariman (fully built)
- Octavia Puzzle Room in Lua. (low chance for a fully built Forma)

# Orokin Catalysts & Reactors: Capacity Increase

Both of these items increase mod capacity by multiplying the current mod capacity by **2**.

### Orokin Catalyst & Reactor Sources

- Both can be obtained reliably from the Nightwave Creds Store.
- Starchart Events / Alerts as indicated by a warning icon on the top right corner of icons.
