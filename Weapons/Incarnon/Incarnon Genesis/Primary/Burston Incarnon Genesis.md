## Incarnon Evolutions

> [!NOTE]
> Weak Point hits charge Incarnon Transmutation; Alt Fire transmutes. Switching back will expend any remaining charge.

These are the Evolutions used with all of the builds below. If there are multiple evolutions picked in the same node, they are ordered in priority from first to last.

| Evolution                   | Description                                                                                           |
| --------------------------- | ----------------------------------------------------------------------------------------------------- |
| `I`: Incarnon Form          | Gain an Auto Fire mode and deal Radial Heat damage. Base Radial Range is 2m with 100% damage falloff. |
| `II`: Forceful Finality (1) | Increase Base Damage by +42<br>+5 Base Multishot on final magazine burst.                             |
| `III`:  Kinetic Battle (3)  | -50% Weapon Recoil                                                                                    |
| `IV`: Fatal Affliction (3)  | +40% Direct Damage per Status Type affecting the target.                                              |
