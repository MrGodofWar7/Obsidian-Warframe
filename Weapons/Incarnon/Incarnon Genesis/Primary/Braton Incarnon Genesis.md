# Braton Prime Builds

## Incarnon Evolutions

> [!NOTE]
> Weak Point hits charge Incarnon Transmutation; Alt Fire transmutes. Switching back will expend any remaining charge.

These are the Evolutions used with all of the builds below. If there are multiple evolutions picked in the same node, they are ordered in priority from first to last.

| Evolution                   | Description                                                                                                             |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `I`: Incarnon Form          | Gain Radial Heat Damage. Base Radial Range is 3m with 10% damage falloff.                                               |
| `II`: Daring Raverie (1)    | Increase Base Damage by +4<br><br>With Channeled Ability active:<br>Increase Base Damage by +38<br>+50% Ammo Efficiency |
| `III`: Void's Guidance (2)  | +60% Accuracy<br>-60% Weapon Recoil                                                                                     |
| `IV`: Critical Parallel (1) | Increase Base Critical Chance by +18%<br>Increase Base Critical Damage Multiplier by +0.2x                              |

While you *can* technically use the evolutions tailored for `II`: Munitions Grit (2) which includes both `III`: Mercenary Chamber (1) and `III`: Gunsmoke Pick Up (3), the weapon becomes *very* ammo hungry.
