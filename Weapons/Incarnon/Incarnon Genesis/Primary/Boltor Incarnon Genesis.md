# Boltor Prime Builds

## Incarnon Evolutions

> [!NOTE]
> Weak Point hits charge Incarnon Transmutation; Alt Fire transmutes. Switching back will expend any remaining charge.

These are the Evolutions used with all of the builds below. If there are multiple evolutions picked in the same node, they are ordered in priority from first to last.

| Evolution                     | Description                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| `I`: Incarnon Form            | Prioritize Slash Damage and gain Multishot.                                           |
| `II`: Crimson Overture (2)    | On Kill: Increase Base Damage by +2 and +20% Ammo Efficiency for 5s. Stacks up to 3x. |
| `III`: Swift Deliverance (1)  | +60% Projectile Speed                                                                 |
| `IV`: Commodore's Fortune (3) | Increase Base Critical Chance by +14%                                                 |
